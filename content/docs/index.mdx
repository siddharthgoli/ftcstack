# Welcome to FTC Code Companion!

Welcome to **FTC Code Companion**, a step by step guide to building a modern FTC codebase.

Whether you're brand new to programming or looking to improve the structure of your team's software, this course is designed to take you from a blank project to a clean, scalable robot codebase.

Unlike many tutorials that only teach you how to make a robot drive, this curriculum focuses on **how competitive teams actually develop software**. Along the way, you'll learn not only how to write code, but also how to organize projects, collaborate with Git, debug effectively, and build software that can grow throughout an FTC season.

Each lesson builds on the previous one, so it's recommended that you complete them in order.

## What you'll need

Before you begin, you should have:

- A Windows, macOS, or Linux computer
- An internet connection
- A willingness to learn
- No prior FTC programming experience required

Some familiarity with Java is helpful, but we'll explain concepts as we go.

## What you'll build

By the end of this curriculum, you'll have:

- A complete FTC development environment
- A solid understanding of the FTC SDK
- Experience using Git and GitHub
- A well organized robot codebase
- The knowledge needed to continue building advanced autonomous and TeleOp systems

Ready to get started?

Continue to the first lesson and begin building your competitive codebase.
