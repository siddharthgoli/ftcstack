Welcome to **FTC Stack**, a step by step guide to building a competitive FTC codebase.

Whether you're brand new to programming or looking to improve the structure of your team's software, this course is designed to take you from a blank project to a clean, scalable robot codebase.

Unlike many tutorials that either only teach the basics or are geared towards a specific resource, this curriculum focuses on **how competitive teams actually develop software**. Along the way, you'll learn not only how to write code, but also how to organize projects, debug effectively, and build software that can grow throughout an FTC season.

## What you'll need

Before you begin, you should have:

- A Windows, macOS, or Linux computer
- An internet connection
- A willingness to learn
- No prior FTC programming experience required

Some familiarity with Java is helpful, but we'll explain concepts as we go.

## What you'll build

By the end of this curriculum, you'll have:

- A complete FTC development environment
- A solid understanding of the FTC SDK
- A well organized robot codebase
- The knowledge needed to continue building advanced autonomous and TeleOp systems

Continue to the first lesson and begin building your very own competitive codebase.
