# Cascaded Controllers

Cascaded controllers combine multiple loops so one controller sets a target for another. This is useful when a robot system needs layered behavior.

## FTC connection

An outer position loop may tell an inner velocity loop what to do, which can make motion smoother and easier to tune.

## Common mistakes

- Adding layers without a clear reason.
- Making the system harder to debug than the robot problem itself.
- Tuning the outer loop before the inner loop behaves well.
