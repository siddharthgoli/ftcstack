# Motion Profiling

Motion profiling plans how a robot should speed up, travel, and slow down. It makes motion more predictable and often easier on hardware.

## FTC connection

Use motion profiles when abrupt starts and stops would make the robot less accurate or less stable.

## Common mistakes

- Using aggressive motion the robot cannot physically follow.
- Ignoring acceleration and deceleration limits.
- Mixing profile math with unrelated robot logic.
