# What is Control Theory?

Control theory is the study of how a system reaches and stays at a desired behavior. On an FTC robot, that means using feedback to correct motion rather than hoping a direct power command is enough.

## FTC intuition

If the arm is supposed to stay at a height, the code should keep checking whether the arm is actually there and adjust power when it is not.

## Why it matters

- It makes the robot more consistent.
- It reduces drift and overshoot.
- It improves autonomous accuracy.
