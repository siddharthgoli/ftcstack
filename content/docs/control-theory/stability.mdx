# Stability

Stable control systems respond to changes without bouncing around or exploding into erratic motion. Stability is one of the first things to watch when tuning FTC mechanisms.

## FTC connection

A stable robot reaches its target smoothly and stays there instead of constantly hunting.

## Common mistakes

- Tuning for speed without checking for oscillation.
- Ignoring how load changes affect behavior.
- Using the same settings for very different mechanisms.
