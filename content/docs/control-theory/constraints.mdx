# Constraints

Constraints define the safe or realistic limits for speed, acceleration, and other motion values. They stop the robot from demanding behavior it cannot achieve.

## FTC connection

Good constraints help the code match the real drivetrain or mechanism.

## Common mistakes

- Assuming the robot can move as fast as the math allows.
- Ignoring battery, load, and friction changes.
- Using one set of limits for every mechanism.
