# Kalman Filters

Kalman filters are an advanced estimation tool that combine motion and sensor data while accounting for uncertainty.

## FTC connection

They can help when the robot needs better state estimates than a single sensor can provide.

## Common mistakes

- Using the filter before understanding the simpler control problems.
- Ignoring the quality of the measurement inputs.
- Treating the math as magic instead of a model.
