# Filters

Filters smooth noisy sensor data so the robot reacts to real changes instead of every tiny fluctuation.

## FTC connection

They are useful when readings jump around too much for stable control.

## Common mistakes

- Over-filtering and adding too much lag.
- Filtering without understanding what noise is actually present.
- Hiding a broken sensor behind smoothing.
