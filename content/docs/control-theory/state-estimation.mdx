# State Estimation

State estimation combines sensor data and control behavior to infer the robot’s current state. It is useful when the robot cannot directly measure everything it needs.

## FTC connection

Localization and pose tracking are common examples of state estimation on FTC robots.

## Common mistakes

- Trusting one sensor completely.
- Ignoring uncertainty.
- Using estimated values without checking whether they still make sense.
