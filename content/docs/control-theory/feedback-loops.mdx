# Feedback Loops

A feedback loop measures the robot, compares it to a target, and makes a correction. This is the basic shape of most useful control systems in FTC.

## FTC connection

Drivetrain heading correction, arm position hold, and velocity control all use feedback ideas.

## Common mistakes

- Correcting too aggressively.
- Forgetting to measure the current state.
- Using feedback without understanding the target and error.
