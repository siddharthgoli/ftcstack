# Classes and Objects

A class describes a type of thing. An object is one real instance of that thing. FTC code uses classes to represent subsystems, hardware wrappers, and reusable logic units.

## FTC example

```java
public class Intake {
    private final DcMotor motor;

    public Intake(DcMotor motor) {
        this.motor = motor;
    }

    public void run(double power) {
        motor.setPower(power);
    }
}
```

## What this gives you

- Cleaner code boundaries.
- Easier team collaboration.
- Reusable robot behavior.

## Common mistakes

- Putting every piece of logic directly in OpMode.
- Using static state everywhere instead of clear object ownership.
- Naming classes after implementation details instead of robot roles.

## FTC connection

Classes help a team express the robot as a set of systems instead of a pile of unrelated commands.
