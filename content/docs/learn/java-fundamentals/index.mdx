# Java Fundamentals

FTC robot code is still Java. This section covers the concepts that show up constantly in robot code: variables, methods, classes, object-oriented design, interfaces, enums, collections, and exceptions.

## Suggested order

1. Variables and data types
2. Methods
3. Classes and objects
4. Object-oriented programming
5. Interfaces
6. Enums
7. Collections
8. Exceptions

## Why this section matters

The goal is not to learn Java in the abstract. The goal is to understand the language well enough to build readable FTC software.
