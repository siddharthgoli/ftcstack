# Variables and Data Types

Variables store information your robot needs while it runs. In FTC code, they often hold motor power, sensor readings, loop timing, or configuration values.

## FTC example

```java
double drivePower = 0.6;
int intakeTargetTicks = 1200;
boolean armReady = false;
```

## What to remember

- Use `double` for most power and position values.
- Use `int` for counts and whole-number states.
- Use `boolean` for conditions like enabled, ready, or active.

## Common mistakes

- Using the wrong numeric type and losing precision.
- Hard-coding values everywhere instead of naming them clearly.
- Treating state values as magic numbers instead of readable variables.

## FTC connection

Clear variables make tuning easier because the team can read what each number means during a match or practice session.
