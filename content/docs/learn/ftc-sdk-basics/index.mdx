# FTC SDK Basics

The FTC SDK is the set of classes and APIs your robot code uses to talk to hardware and driver station input. This section explains the pieces you use every day while building a robot codebase.

## Topics

- Project structure
- OpModes
- HardwareMap
- Motors
- Servos
- Sensors
- Gamepads
- Telemetry

## Why this matters

If you understand the SDK well, you can write code that is easier to debug, easier to organize, and easier to hand off between students.
