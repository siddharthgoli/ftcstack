# Project Structure

FTC projects separate robot code, libraries, and resources so the team can work safely inside the same repository.

## Common areas

- TeamCode for team-written robot code.
- External libraries for shared or third-party code.
- Resources for configuration and assets.

## Common mistakes

- Editing the wrong module.
- Letting utility code spread across unrelated folders.
- Ignoring structure until the project is hard to navigate.

## FTC connection

Good structure makes it possible for multiple students to work on the same season without stepping on each other’s changes.
