Sensors allow a robot to measure information about the world around it.

Without sensors, a robot can only follow instructions. With sensors, a robot can react and make decisions based on feedback.

## Why Use Sensors?

Sensors improve robot reliability by allowing programs to:

- Detect objects
- Measure position
- Track movement
- Maintain accuracy
- React to changes

For example, instead of running a motor for a specific amount of time, a robot can use encoder feedback to move a precise distance.
