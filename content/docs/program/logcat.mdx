# Logcat

Logcat shows Android and app logs from the Robot Controller device. It is useful when telemetry is not enough and the robot app is failing deeper in the stack.

## FTC connection

Use logcat for startup issues, crashes, and problems that happen before the robot can report useful telemetry.

## Common mistakes

- Waiting until the match to learn how to read logs.
- Ignoring repeated warnings that reveal the real problem.
- Treating log output as optional during debugging.
