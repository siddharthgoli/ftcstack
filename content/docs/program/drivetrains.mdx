# Drivetrains

The drivetrain is the robot system drivers feel most directly. Good drivetrain code should make the robot predictable, tunable, and easy to debug.

## FTC connection

Keep power shaping, heading correction, and drive mode logic together so the team can tune them without touching unrelated code.

## Common mistakes

- Hard-coding drive behavior deep in the loop.
- Mixing mecanum math with every other subsystem.
- Forgetting to normalize power when needed.
