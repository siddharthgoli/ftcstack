# Road Runner

Road Runner is another common FTC motion library. Teams use it for path following, motion control, and localization support.

## FTC connection

It is useful when the team wants tested motion patterns instead of hand-rolled drive math.

## Common mistakes

- Assuming a library removes the need for tuning.
- Mixing library setup with unrelated robot logic.
- Not validating motion behavior on the real field.
