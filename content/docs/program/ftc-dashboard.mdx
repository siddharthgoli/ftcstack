# FTC Dashboard

FTC Dashboard is useful for tuning values, watching robot state, and displaying useful graphs or controls during development.

## FTC connection

It is most useful when the team wants to tune behavior without constantly rebuilding the code.

## Common mistakes

- Treating dashboard tooling as a replacement for good code structure.
- Exposing every variable instead of the ones that matter.
- Not validating dashboard changes on the real robot.
