# Performance Optimization

Performance optimization is about making the robot software reliable under real match conditions. The most important part is knowing what actually slows the robot down.

## FTC connection

Focus on the parts that affect driver feel, control accuracy, and autonomous consistency.

## Common mistakes

- Optimizing the wrong thing.
- Rewriting code for speed before measuring.
- Adding complexity that hurts readability more than it helps performance.
