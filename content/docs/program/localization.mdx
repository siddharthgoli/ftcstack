# Localization

Localization estimates the robot’s current pose using sensors and motion data. It is critical when autonomous must be repeatable and accurate.

## FTC connection

Localization makes it possible to drive to field targets, follow paths, and correct drift.

## Common mistakes

- Trusting sensor data without validation.
- Ignoring drift over time.
- Debugging localization after the autonomous path already depends on it.
