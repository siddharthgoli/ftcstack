# Command-Based Programming

Command-based programming turns robot behavior into reusable actions that can be scheduled and combined. It is useful when a team wants a cleaner way to sequence complex behavior.

## Why use it

- It keeps behavior reusable.
- It helps separate intent from execution.
- It works well when multiple robot actions need to coordinate.

## FTC connection

The pattern is especially helpful in Autonomous or when driver actions trigger complex sequences.

## Common mistakes

- Adopting the pattern without understanding its maintenance cost.
- Recreating the same code paths in commands and subsystems.
- Making the scheduler harder to understand than the robot problem itself.
