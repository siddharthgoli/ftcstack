# Android Studio Debugger

The debugger helps when telemetry and logs do not explain the behavior clearly enough. It is especially useful for setup code, state changes, and complex control logic.

## FTC connection

Use it to inspect values that should change in a predictable way while the robot runs.

## Common mistakes

- Trying to debug live driver behavior without first narrowing the problem.
- Setting too many breakpoints.
- Relying on the debugger instead of understanding the code path.
