# Events

Events let code react to a condition becoming true. FTC teams often use them to keep driver logic or autonomous transitions responsive without extra clutter.

## FTC connection

An event might fire when a target position is reached, when a sensor crosses a threshold, or when a driver action should begin a new sequence.

## Common mistakes

- Treating every check as an event.
- Making events do too much work.
- Ignoring when the event should stop being active.
