# Loop Time

Loop time is the amount of time each update cycle takes. Keeping loop time reasonable matters because FTC code should stay responsive to drivers and sensors.

## FTC connection

If the loop gets too slow, the robot can feel laggy or miss important state changes.

## Common mistakes

- Doing heavy work every loop without need.
- Ignoring timing until the robot starts feeling unresponsive.
- Mixing logging and expensive logic into the main update path.
