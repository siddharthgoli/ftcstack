# Poses

A pose is the robot’s position and orientation together. Poses are the basic building block of autonomous movement and localization.

## FTC example

```java
Pose2d pose = new Pose2d(x, y, heading);
```

## FTC connection

If pose data is wrong, motion planning and localization will also be wrong.

## Common mistakes

- Treating position and heading as unrelated values.
- Not tracking units.
- Updating pose in more than one place without clear ownership.
