# Bulk Reads

Bulk reads are a performance optimization that helps teams read hardware data more efficiently. They are useful when the robot polls many devices every loop.

## FTC connection

If the robot reads a lot of sensor or encoder data, bulk reads can reduce unnecessary overhead and keep control responsive.

## Common mistakes

- Optimizing before measuring a real problem.
- Using the technique without understanding what it changes.
- Ignoring the rest of the code’s runtime cost.
