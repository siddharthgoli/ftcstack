# Pedro Pathing

Pedro Pathing is a pathing option teams can use for structured autonomous movement. The useful part is not the library name itself, but the way it helps the team define motion clearly.

## FTC connection

Use it when your team wants a repeatable way to describe autonomous movement and tuning.

## Common mistakes

- Treating the library as a substitute for understanding robot motion.
- Copying sample code without adapting it to the real robot.
- Ignoring the impact of tuning on field performance.
