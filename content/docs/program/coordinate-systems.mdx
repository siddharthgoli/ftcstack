# Coordinate Systems

Coordinate systems tell the robot where it is and how it should move. FTC autonomous code becomes easier to reason about when the team clearly separates field coordinates from robot coordinates.

## FTC connection

If your team knows which coordinate frame a value belongs to, pathing and localization become much easier to debug.

## Common mistakes

- Mixing frames without naming them.
- Assuming a heading means the same thing everywhere.
- Debugging motion without knowing the coordinate system behind it.
