# Mechanism Control

Mechanism control covers every part of the robot that is not the drivetrain. Arms, lifts, claws, intakes, and shooters all benefit from clear high-level control methods.

## FTC connection

Control code should describe the robot goal, not just raw motor power.

## Common mistakes

- Directly setting motor power from many places.
- Not separating manual control from automatic hold logic.
- Failing to define safe limits.
