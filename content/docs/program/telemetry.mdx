# Telemetry

Telemetry is the first line of debugging for many FTC issues. Good telemetry tells the team what the code believes is happening right now.

## FTC connection

Show the values that explain behavior, not every value you can print.

## Common mistakes

- Printing too much data.
- Forgetting to update or clear old information.
- Using telemetry too late in the debugging process.
