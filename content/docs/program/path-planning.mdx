# Path Planning

Path planning is how the robot decides the route it should follow in autonomous. Good planning balances scoring strategy, robot speed, and reliability.

## FTC connection

Teams often use pathing libraries and their own motion rules together, so the software should keep the route logic readable.

## Common mistakes

- Building paths that are too ambitious for the robot.
- Hiding important motion behavior inside one giant routine.
- Ignoring the cost of stopping, turning, and correcting.
