# Contributing

Contributions should improve the curriculum, keep the docs focused, and preserve the professional tone of the site.

## Good contributions

- Clearer explanations.
- Better FTC examples.
- Useful snippets and references.
- Fixes that improve structure or readability.

## What to avoid

- Duplicate pages for the same idea.
- Generic programming explanations without FTC context.
- Large walls of text that are hard to navigate.
